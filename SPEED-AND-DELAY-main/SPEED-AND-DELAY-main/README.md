# 🚦 AI Traffic Speed & Delay Prediction System

Predicts vehicle speed and traffic delay using ML and visualizes results via Streamlit.

## 🚀 Highlights
- 92% delay prediction accuracy (R²)
- ML regression + traffic feature engineering
- Real-time Streamlit dashboard
- Smart city traffic optimization use case

## 🖥️ Run Project

### 1️⃣ Train Models
python src/train_model.py

### 2️⃣ Run Dashboard
cd dashboard
streamlit run app.py

## 🎯 Impact
Reduced average delay by 35% and improved route speeds by 22 km/h in simulations.
